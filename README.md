# SiSH - Simple MyShell
SiSH (Simple Shell) is a custom shell program developed for the Operating Systems & Advanced Mobile course at Dankook University. It allows users to execute commands, run programs, and interact with the operating system in a simple and intuitive way. Features include executing system commands like `ls`, `pwd`, `echo`, `whoami`, `date`, support for command arguments (e.g., `ls -l /home`), executing commands using absolute paths (e.g., `/bin/ls`), a custom prompt showing the username (`javok@SiSH>`), and handling invalid commands gracefully with error messages. To compile and run, use `make` to build the program, then run `./sish` to start the shell. Type `quit` at the prompt to exit. Example usage: `javok@SiSH> ls` shows files, `javok@SiSH> pwd` prints the current directory, `javok@SiSH> echo This is my shell test` prints a message, and `javok@SiSH> quit` exits the shell. The project structure is: `os_hw_1/` containing `sish.c` (main source code), `Makefile` (to compile SiSH), `README.md` (project overview and instructions), and `.gitignore` (to ignore compiled binaries like *.exe or *.o).
